# Programmatic Video Protocol (SuperSkill)

This SuperSkill orchestrates code-driven video creation, combining Remotion React compositions, Manim algorithmic animations, and deterministic FFmpeg stitching.

## Execution Phases & Progressive Disclosure

### Phase 1: Remotion React Video Compositions
> *Load reference module for React video*:
> Read [`references/remotion-patterns.md`](references/remotion-patterns.md)
- Build 9:16 vertical reels using React components, spring physics, and dynamic typography.
- Use `useCurrentFrame`, `interpolate`, and `spring` for frame-accurate animations.

### Phase 2: Manim Technical & System Explainers
> *Load reference module for programmatic vector diagrams*:
> Read [`references/manim-explainers.md`](references/manim-explainers.md)
- Generate clean, animated vector diagrams for complex architecture, flows, and graphs.

### Phase 3: FFmpeg Stitching, Transitions & Audio Ducking
> *Load reference module for FFmpeg media processing*:
> Read [`references/ffmpeg-stitching.md`](references/ffmpeg-stitching.md)
- Automated video cuts, aspect ratio padding, audio duration guardrails, and music ducking.

## Output Format
Deliver reproducible rendering scripts and exact FFmpeg / Remotion commands.
