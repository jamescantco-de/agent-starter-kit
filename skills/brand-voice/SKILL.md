# Brand Voice & Anti-Cliché Guide

AI models default to an inflated, homogenised corporate dialect unless specifically restrained. This skill keeps writing grounded, human, and authentic.

## 1. The Banned Vocabulary List
Never use these generic filler words in human-facing content:
- **Transformative** → use *"different"*, *"huge shift"*
- **Leverage** → use *"use"*
- **Synergy** → use *"fit"*, *"alignment"*
- **Delve** → use *"look into"*, *"explore"*
- **Seamless** → use *"smooth"*, *"clean"*
- **Cutting-edge** → use *"modern"*, *"new"*
- **Plethora / Myriad** → use *"a lot of"*, *"plenty of"*
- **Harness / Unlock** → use *"get the most out of"*, *"open up"*

## 2. Voice Principles
- **Concrete over abstract**: Describe the actual thing that happened rather than gesturing at a concept.
- **Vary sentence length**: Mix short bursts with measured explanations. Avoid repetitive punchy bullet points.
- **Understatement over hype**: Real builders speak with quiet confidence. Let the results speak for themselves.
