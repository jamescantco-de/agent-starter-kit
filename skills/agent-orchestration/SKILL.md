# Agent Orchestration Protocol (SuperSkill)

This SuperSkill coordinates autonomous multi-agent engineering workflows, isolated Git worktrees, and adversarial decision councils.

### Phase 1: Parallel DevFleet & Worktree Isolation
> *Load reference module for parallel agent dispatch*:
> Read [`references/devfleet-worktrees.md`](references/devfleet-worktrees.md)
- Dispatch independent tasks across isolated Git worktrees to eliminate branch collisions.
- Coordinate PR reviews and automated merge queues.

### Phase 2: The 4-Voice Decision Council
> *Load reference module for ambiguous decisions*:
> Read [`references/decision-council.md`](references/decision-council.md)
- Convene a four-voice structured disagreement council (Architect, Pragmatist, Adversary, Operator) before making irreversible technical or commercial commitments.

### Phase 3: RFC-Driven DAG Work Units
> *Load reference module for multi-step pipelines*:
> Read [`references/rfc-dag-execution.md`](references/rfc-dag-execution.md)

## Output Format
Deliver clear orchestration plans with defined subagent roles, worktree paths, and gate criteria.
